# DeBug 除蟲專家

一款搞笑的第一人稱除蟲遊戲：拿著殺蟲劑和捕鼠器，到公寓、餐廳廚房、古厝、垃圾場和下水道接案，消滅蟑螂、蜘蛛、蜈蚣、蚊子和老鼠，最後打倒害蟲之王。支援電腦、手機觸控與 Meta Quest VR，直接在瀏覽器裡玩，不需要安裝。

![遊戲畫面](docs/gameplay.jpg)

## 立即遊玩

👉 **https://gp-vincent.github.io/Test/**

用電腦、手機或 Meta Quest 的瀏覽器開啟上面的網址即可。在 Quest 上按「進入 VR」就能用手把遊玩。

## 遊戲特色

- **委託佈告欄**：每次回到除蟲社，佈告欄上都會出現不同的委託，場景、委託人和特殊狀況都是隨機的，沒有固定關卡。
- **害蟲越來越強**：接越多案子聲望越高，害蟲的數量、血量和速度跟著提升，新種類也會陸續登場。
- **五大場景**：公寓、餐廳廚房、古厝、垃圾場（戶外）、下水道，各有不同的光線氣氛。
- **八種害蟲**：美洲蟑螂、德國蟑螂、白額高腳蛛、蜈蚣、斑蚊、老鼠、小鼠、變異鼠，還有金色光環的菁英怪。
- **頭目戰**：聲望累積到一定程度會出現「緊急委託」，最終頭目是下水道深處的害蟲之王。
- **臨時強化道具**：打倒害蟲有機率掉落道具，例如狂暴噴霧、無限罐、冰凍時間、防護罩、急凍炸彈。
- **裝備與天賦**：7 種噴霧罐、4 種捕鼠器、7 項配備升級、8 項天賦。
- **無盡模式**：打倒害蟲之王後解鎖，看你能撐到第幾波。
- **自動存檔**：進度存在瀏覽器裡，下次打開會接著玩。

## 操作方式

| 動作 | 電腦 | 手機 | Meta Quest |
| --- | --- | --- | --- |
| 移動 | WASD | 左下虛擬搖桿 | 左搖桿 |
| 轉向／瞄準 | 滑鼠 | 右半螢幕拖曳 | 右搖桿轉向，用手瞄準 |
| 噴殺蟲劑 | 按住左鍵或空白鍵 | 按住噴霧按鈕 | 右手扳機 |
| 放捕鼠器 | 右鍵或 E | 捕鼠器按鈕 | 左手扳機 |
| 選單 | 滑鼠點選 | 手指點選 | 手把光線指著按扳機 |

## 在自己的電腦上執行

整個遊戲只有一個 `index.html` 檔案。

最簡單的方式是直接用瀏覽器打開 `index.html`。遊戲會從網路載入 three.js 和字型，所以需要連網。

如果要測試 VR 或避免瀏覽器的本機檔案限制，可以在專案資料夾開一個本機伺服器：

```bash
python3 -m http.server 8000
```

然後開啟 `http://localhost:8000`。WebXR（VR 模式）只能在 HTTPS 或 localhost 下運作。

## 部署

這是純靜態網頁，沒有後端，任何靜態網站主機都能放。

- **GitHub Pages**：在儲存庫的 Settings → Pages，來源選擇 `main` 分支的根目錄。
- **Cloudflare Pages**：連結這個儲存庫，或直接上傳 `index.html`。

## 技術說明

- 使用 [three.js](https://threejs.org/) r147 繪製 3D 畫面，WebXR 支援 VR。
- 所有模型、材質和音效都由程式即時產生，沒有外部圖片或音檔。
- 靜態場景合批繪製、害蟲以 InstancedMesh 打包繪製，並依幀率自動調整解析度，以 iPhone 14 與 Quest 2 為效能基準。
- 存檔使用瀏覽器 localStorage，鍵名為 `debug-save-v1`。

## 已知限制

- iPhone 的 Safari 目前不支援 WebXR，iPhone 上只能用觸控遊玩。
- 存檔存在各自裝置的瀏覽器裡，電腦和手機的進度不會同步；清除瀏覽器資料會讓進度消失。
- 尚未在實體 Quest 2 與 iPhone 上完整測試效能。
